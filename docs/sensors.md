# 追加できるセンサー

バッジに足せるセンサーと入力デバイスの調査メモです（2026-11-09）。本体に載っている部品は [hardware.md](hardware.md) を参照してください。

## どこにつなぐか

バッジの拡張口は 3 種類あります。センサーを足すなら I2C（Qw/ST）を使います。

| 拡張口 | 用途 | 中身 |
|---|---|---|
| **I2C（Qw/ST 端子）** | センサーなどの部品をつなぐ | JST-SH 4 ピン。SDA = GPIO4、SCL = GPIO5、3.3V、GND。`I2C(0, scl=5, sda=4)` |
| SWD | チップのデバッグ・ファームウェアの書き込み（Raspberry Pi Debug Probe など） | アプリ作りでは使わない |
| 金色の穴（6 個） | はんだ付けで自分で配線する | GPIO 4 本 + 電源。I2C 以外の部品用 |

Qw/ST は SparkFun の Qwiic と互換で、部品を数珠つなぎにできます。I2C では各部品を番地で呼び分けるので、番地が重ならなければ同時に使えます。

## ドライバー入りの部品（差せばすぐ使える）

以下はバッジのファームウェアにドライバーが入っている Pimoroni Breakout です。「読み込み」は、バッジの実機で `import` に成功したことを示します（[hardware.md](hardware.md)）。部品をつないでの動作確認は、まだしていません。

番地は [pimoroni/pimoroni-pico](https://github.com/pimoroni/pimoroni-pico) のドライバーのソースで確かめた既定値です。

### 環境

| 測るもの | 部品 | モジュール | 番地 | 読み込み |
|---|---|---|---|---|
| 温度・湿度・気圧 | BME280 | `breakout_bme280` | 0x76（切替 0x77） | ✅ |
| 温度・湿度・気圧・ガス | BME688 | `breakout_bme68x` | 0x76（切替 0x77） | ✅ |
| 温度・湿度・気圧・ガス | BME690 | `breakout_bme69x` | 0x76（切替 0x77） | ✅ |
| 温度・気圧 | BMP280 | `breakout_bmp280` | 0x76（切替 0x77） | ✅ |
| 気圧（高精度。高さの変化がわかる） | ICP10125 | `breakout_icp10125` | 0x63 | ✅ |
| CO2・温度・湿度 | SCD41 | `breakout_scd41` | 0x62 | ✅ |
| 空気の汚れ（VOC、eCO2） | SGP30 | `breakout_sgp30` | 0x58 | ✅ |
| ガス（還元性・酸化性・NH3） | MICS6814 | `breakout_mics6814` | 0x19 | ✅ |

### 動き・距離

| 測るもの | 部品 | モジュール | 番地 | 読み込み |
|---|---|---|---|---|
| 3 軸加速度（傾き・振る・叩く） | MSA301 | `breakout_msa301` | 0x26 | ✅ |
| 距離（8×8 の距離マップ、最大約 4m） | VL53L5CX | `breakout_vl53l5cx` | 0x29 | ✅ |

### 光・色

| 測るもの | 部品 | モジュール | 番地 | 読み込み |
|---|---|---|---|---|
| 明るさ・近接 | LTR559 | `breakout_ltr559` | 0x23 | ✅ |
| 色（RGB + クリア） | BH1745 | `breakout_bh1745` | 0x38（切替 0x39） | ✅ |
| 分光 6 チャンネル | AS7262 | `breakout_as7262` | 0x49 | ✅ |
| 分光 14 チャンネル | AS7343 | `breakout_as7343` | 0x39 | ✅ |

明るさだけなら、本体の照度センサー（`LIGHT_SENSE`）で足ります。

### 入力デバイス・その他

| 種類 | 部品 | モジュール | 番地 | 読み込み |
|---|---|---|---|---|
| トラックボール（RGB LED 付き） | Trackball | `breakout_trackball` | 0x0A（切替 0x0B） | ✅ |
| 回すつまみ | Encoder | `breakout_encoder` | 0x0F | ✅ |
| 回すつまみ（ホイール + LED リング） | Encoder Wheel | `breakout_encoder`（※） | 0x13 と 0x77 の 2 つ | ✅ |
| ボリューム | Potentiometer | `breakout_potentiometer` | 0x0E | ✅ |
| ゲームパッド | Qw/ST Pad | `qwstpad` | 0x21（切替 0x23 / 0x25 / 0x27） | ✅ |
| 時計（RV3028） | RTC | `breakout_rtc` | 0x52 | ✅ |

※ Encoder Wheel 専用の `breakout_encoder_wheel` が使えるかは確かめていません（probe の確認対象に入れていない）。時計は本体にもあるので、RTC Breakout は通常不要です。

## ドライバーはないが使える部品

| 部品 | 測るもの | 番地 | 備考 |
|---|---|---|---|
| SHT41 + SGP41 | 温度・湿度 + VOC・NOx | 0x44 / 0x59 | 公式リポジトリの `badge25/apps/sensor_dashboard` が自前で読む。2025 年版の実機で動作確認済みと README に記載あり |
| SparkFun Qwiic などの他社製品 | さまざま | 部品による | 電気的にはつながるが、MicroPython のコードを自分で用意する必要がある |

## Qw/ST につなげない部品

| 部品 | 理由 |
|---|---|
| PMW3901 / PAA5100（光学式の動き検出） | I2C ではなく SPI でつなぐ。ドライバーは読み込めるが、金色の穴にはんだ付けが必要で、GPIO 4 本では配線がぎりぎり |

## 番地の重なりに注意

- 本体の時計チップが **0x51** を使っています。上の部品はどれも 0x51 を使わないので、本体とはぶつかりません。
- 部品同士では、次の組み合わせがぶつかります。
  - **Encoder Wheel（0x77）** と、0x77 に切り替えた BME280 / BME688 / BME690 / BMP280。これらの環境センサーは既定の 0x76 のまま使います。
  - **AS7343（0x39）** と、0x39 に切り替えた BH1745。
  - **LTR559（0x23）** と、0x23 に切り替えた Qw/ST Pad。
- 番地の切り替えは、部品の裏のジャンパー（はんだで橋をかける場所）で行うものが多いです。
- つないだ部品の番地は、probe アプリを起動すると I2C の接続先一覧に出ます。

## 用途別のおすすめ

| やりたいこと | 部品 | 理由 |
|---|---|---|
| 振る・傾けるアプリ（サイコロ、傾けて遊ぶゲーム） | MSA301 | このバッジに無い加速度センサーを足せる |
| 部屋の環境モニター | BME688 | 温度・湿度・気圧・ガスを 1 枚で測れる |
| 換気のタイミングを知らせる | SCD41 | CO2 を直接測れる（推定値ではない） |
| 手をかざして操作する | VL53L5CX | 8×8 の距離マップで、手の位置や動きがわかる |

## 用意するもの

- Qw/ST（JST-SH 4 ピン）ケーブル。Breakout に付いていない場合は別に買う
- Pimoroni Breakout は 3.3V で動く（多くは 3〜5V 対応）。バッジの Qw/ST は 3.3V
